# Epsylo

**Translation that explains itself.** → [epsylo.app](https://epsylo.app)

Every translation comes with a word-by-word breakdown: each segment
colour-coded by grammatical role, with its dictionary form, an explanation
and alternatives, plus syntax cards and dependency trees.

- 97 languages. English, Italian, Japanese and Spanish have hand-written
  language profiles; the other 93 are marked Beta.
- Live controls: politeness (blunt → honorific, four levels) and emphasis,
  which can target single words.
- Vocabulary bank with spaced review, on your device, works offline.
- Free plan: 20 translations a month.

The app's source is private.
